# 中文字符统计工具

## 1. 项目简介

这是一个使用 Python 编写的中文字符统计小项目，用于练习 Python 基础语法、字符串处理和程序逻辑。

项目通过对输入文本进行处理，统计文本中的中文字符数量。

## 2. 项目功能

- 读取或接收待统计的文本
- 识别文本中的中文字符
- 统计中文字符数量
- 输出统计结果

> 请根据当前代码的实际实现，删除尚未支持的功能。

## 3. 技术栈

- Python
- 字符串处理
- 条件判断与循环

## 4. 环境要求

- 已安装 Python 3
- 可使用 PyCharm 或命令行运行

## 5. 运行方法

1. 克隆或下载本项目。
2. 使用 PyCharm 打开项目目录。
3. 打开实际的 Python 主程序文件。
4. 运行程序并按照提示输入文本（如果程序需要输入）。

如果使用命令行，请将下面的文件名替换为项目中真实的入口文件：

```bash
python main.py
```

## 6. 运行示例

以下仅为示例，实际输入方式和输出格式以程序为准。

输入：

```text
你好，Python！
```

预期统计结果：如果只统计两个汉字“你好”，中文字符数量为 2。
